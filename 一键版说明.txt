一键版 — L4 想法到视频

使用方法
1. 打开「一键版.ipynb」，或通过 GitHub README 的一键版 Colab 链接打开。
2. 选择 NVIDIA L4 GPU、高内存运行时（目标配置 64GB 内存、24GB 显存、200GB 硬盘）。
3. 点击「运行时 → 全部运行」，无需修改任何开关或输入密码。
4. 等待自动检查、安装、GPU 自检和模型下载完成。首次下载为数十 GB。
5. 最后一个单元格显示公网 HTTPS 地址、账号 owner，以及自动生成的 32 字符随机密码。
6. 打开地址登录，在网页输入想法并点击「生成短片」，查看文案、首帧、视频结果。

默认行为
默认启用 FastAPI 网页/API 和 Cloudflare Quick Tunnel。密码通过安全随机源生成，只有本地及公网鉴权自检通过后才显示。
自动继承 Xet 下载加速、SD-Turbo 重复权重筛选及新版隧道诊断。
安装与模型文件位于 /content/wan_l4_oneclick。若普通版的模型缓存仍存在，会复用缓存，无需重复下载已完成文件。
安装、下载、网页待机阶段主要使用 CPU/磁盘/网络，GPU 低利用率正常；网页提交任务后运行 GPU 推理。
启动时不自动生成示例视频，避免占用 GPU 和增加首次等待。默认短片为 33 帧、20 步、24 FPS。
同一运行时再次全部运行时，若本一键版服务仍正常，会复用服务和密码；新会话生成新密码。

凭据和关闭
密码只保留在运行时内存和最后显示的输出，不写入源码、配置或日志。请保存凭据，分享笔记本前清除输出。
Colab 断开回收、重启或 cloudflared 停止后，临时地址可能失效。
需要主动关闭时，在新单元格执行 stop_oneclick()。它关闭本一键版的网页、隧道和匹配的生成进程，保留缓存与文件。
普通版和一键版使用不同服务目录，并自动选择本地端口。
